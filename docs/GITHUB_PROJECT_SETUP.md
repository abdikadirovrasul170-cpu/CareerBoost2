# GitHub Projects тақтасын жасау нұсқаулығы

Бұл файл репозиторийге арналған ұсынылатын тақта мазмұнын береді. GitHub-та тақта мен milestone-дарды аккаунт атынан жасау үшін GitHub жүйесіне кіріп, төмендегі әрекеттерді орындау қажет.

## Milestones
1. **MVP** — тіркелу, профиль, вакансия, іздеу және өтінімнің негізгі ағыны.
2. **Final** — қалған User Story, алты паттерн, тесттер және құжаттама.
