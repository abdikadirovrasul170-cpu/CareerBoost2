# CareerBoost — User Stories және Acceptance Criteria

| ID | User Story | Қабылдау критерийлері |
|---|---|---|
| US-01 | Кандидат ретінде жүйеге тіркелгім келеді, профиль жасай алу үшін. | Бірегей email қабылданады; қайталанған email қабылданбайды; бос email қабылданбайды. |
| US-02 | Тіркелген қолданушы ретінде жүйеге кіргім келеді. | Дұрыс email/құпиясөз қабылданады; қате дерекке қате хабарламасы беріледі. |
| US-03 | Кандидат ретінде кәсіби профиль құрғым келеді. | Аты мен мамандығы сақталады; профиль идентификаторы беріледі. |
| US-04 | Кандидат ретінде дағдыларымды жаңартқым келеді. | Дағдылар тізімі жаңартылады; бос дағды қабылданбайды. |
| US-05 | Жұмыс беруші ретінде вакансия жариялағым келеді. | Атауы мен компаниясы сақталады; жалақы нөлден төмен болмауы керек. |
| US-06 | Кандидат ретінде барлық вакансияны көргім келеді. | Жарияланған вакансиялар тізімі қайтарылады. |
| US-07 | Кандидат ретінде дағды бойынша вакансия іздегім келеді. | Сүзгі сәйкес дағдысы бар вакансияларды ғана қайтарады. |
| US-08 | Кандидат ретінде вакансияға өтінім бергім келеді. | Өтінім вакансия және кандидатпен байланысады; бір вакансияға қайталама өтінім қабылданбайды. |
| US-09 | Кандидат ретінде өтінімді кері қайтарғым келеді. | Өз өтінімі табылып, мәртебесі WITHDRAWN болады. |
| US-10 | Кандидат ретінде маған сай вакансия ұсыныстарын алғым келеді. | Strategy дағдылар сәйкестігіне қарай ұсыныстарды реттейді. |
| US-11 | Жұмыс беруші ретінде сұхбатқа шақыру уақытын белгілеуді қалаймын. | Шақыру хабарламасы жасалады; Abstract Factory хабарлама түрін таңдайды. |
| US-12 | Кандидат ретінде профиль бойынша қысқаша есеп алғым келеді. | Visitor профильдегі дағдылар санын және қорытынды мәтінді шығарады. |

## MVP және Final
- **MVP:** US-01–US-08, консольдік деректер, негізгі валидация.
- **Final:** US-09–US-12, алты паттернді толық демонстрациялау, JUnit тесттері және құжаттама.
